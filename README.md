# DJI SN 批量激活查询助手

![Version](https://img.shields.io/badge/version-1.1.0-1477c9)
![Manifest](https://img.shields.io/badge/Chrome-Manifest%20V3-4285F4)
![Browser](https://img.shields.io/badge/browser-Chrome%20%7C%20Edge-087f5b)
![Storage](https://img.shields.io/badge/data-local%20only-60656d)

一个运行在大疆设备信息查询页中的 Chrome / Edge 扩展，用来管理 SN 批量队列、自动记录设备激活结果，并导出 CSV。

> 本项目是非官方辅助工具，与 DJI 大疆创新无隶属或合作关系。

## 它能做什么

- 批量导入 SN，支持换行、空格、逗号和分号分隔
- 自动转为大写、校验格式并忽略重复项
- 自动填入当前 SN
- 滑块验证通过后自动点击查询
- 自动识别产品名称、激活状态和激活时间
- 自动返回查询页并继续下一条
- 支持暂停、跳过、重试和人工修正结果
- 将完整队列导出为带 BOM 的 UTF-8 CSV，可直接用 Excel 打开
- 队列和结果仅保存在浏览器本地

## 工作流程

```text
粘贴 SN → 加入队列 → 开始查询 → 手动完成滑块
                                      ↓
                         自动查询 → 自动记录结果
                                      ↓
                         自动返回 → 填入下一条
```

大疆官网使用人机验证滑块。扩展不会绕过或模拟破解验证码，因此每条查询仍需要人工完成滑块；默认连续模式会自动完成滑块之后的查询、记录和队列推进。

## 安装

本项目暂未发布到 Chrome Web Store，需要通过开发者模式安装。

1. 从 [Releases](https://github.com/Jonxinxin/dji-sn-batch-checker/releases/latest) 下载最新版 ZIP 并解压；也可以使用仓库的 **Code → Download ZIP**。
2. 打开浏览器扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `dji-sn-batch-checker` 文件夹。
6. 打开[大疆设备信息查询页](https://repair.dji.com/device/detail?re=cn&lang=zh-CN)。

页面右侧出现“SN 批量激活查询”面板即表示安装成功。

## 使用方法

1. 将 SN 粘贴到“导入序列号”文本框。
2. 点击“加入队列”，然后点击“开始查询”。
3. 扩展会自动把当前 SN 填入大疆官网输入框。
4. 手动完成官网滑块。
5. 默认连续模式会自动点击查询、记录结果并填入下一条。
6. 全部完成后点击“导出 CSV”。

如果希望逐条检查结果，可以关闭“验证后自动查询、记录并进入下一条”。

## 结果识别与人工修正

扩展会优先根据当前 SN 和官网返回的具体激活时间判断结果，避免把页面说明中的“激活时间”误识别为查询结果。

如果大疆官网改版后未能自动识别：

1. 点击“记录当前页”保存官网结果原文。
2. 使用“标记已激活”“标记未激活”或“待确认”修正状态。
3. 在 GitHub Issues 中提交脱敏后的页面结构或截图，便于更新识别规则。

请在反馈截图中遮挡真实 SN、账号及其他个人信息。

## 数据与权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 在扩展本地存储中保存 SN 队列、查询结果和面板设置 |
| `https://repair.dji.com/device/*` | 仅在大疆设备查询相关页面加载操作面板 |

- 不需要服务器，不包含统计或遥测代码。
- 不会将 SN 队列或结果上传到第三方服务。
- 不会读取其他网站页面。
- 卸载扩展会同时移除其浏览器本地数据；重要结果请先导出 CSV。

## 格式与兼容性

- SN：14–20 位字母或数字，与大疆当前页面校验规则一致
- 浏览器：最新版 Chrome、Edge，以及兼容 Manifest V3 的 Chromium 浏览器
- 页面区域：中国大陆简体中文设备信息查询页
- 导出格式：UTF-8 CSV

## 常见问题

### 为什么不能自动拖动滑块？

滑块用于识别人类操作。自动模拟或绕过会规避网站的人机验证机制，也容易触发风控。扩展只自动化验证完成后的步骤。完全无人值守需要大疆提供正式的批量查询 API 或合作方接口。

### 官网已经显示结果，面板仍停在“查询中”怎么办？

先确认使用的是 `1.1.0` 或更高版本，然后在扩展管理页点击“重新加载”并刷新大疆页面。扩展会重新读取当前结果页。仍未识别时可点击“记录当前页”并人工标记。

### 为什么第二条没有自动开始？

确认“验证后自动查询、记录并进入下一条”已勾选。如果上一条结果被标记为“待确认”，扩展会暂停，等待人工确认后再继续。

### 如何清除数据？

可在队列中逐条删除、点击“清除已完成”，或在浏览器扩展管理页删除该扩展的站点数据。

## 开发与测试

项目不依赖构建工具或第三方运行时。修改文件后，在扩展管理页点击“重新加载”并刷新大疆页面即可。

运行核心测试：

```powershell
node tests/core.test.js
```

检查 JavaScript 语法：

```powershell
node --check core.js
node --check content.js
```
