DJI SN 批量查询助手 · Windows EXE 版

运行要求
Windows 10 / 11，64 位；已安装 Microsoft Edge 或 Google Chrome，并可访问大疆官网。
EXE 已包含 Python、界面组件和运行依赖，无需安装 Python 或浏览器扩展。

使用方法
1. 将 DJI-SN-Checker.exe 复制到本机文件夹，双击打开。
2. 点击“打开浏览器 / 登录”，在查询窗口登录自己的 DJI 账号并返回查询页。
3. 粘贴 SN，点击“加入队列”，再点击“开始 / 继续”。
4. 自动尝试上限默认 3 次（含首次），可设置为 1–10 次。失败后在当前标签页刷新重试；达到上限后请手动滑动。
5. 全部完成后会保存结果、自动关闭查询浏览器，并在主界面弹出完成统计。点击“导出 CSV”保存表格。

数据保存与更新
EXE 版将查询队列、设置、浏览器登录状态及诊断记录保存在：
%LOCALAPPDATA%\DJI-SN-Checker
将上面这一行粘贴到资源管理器地址栏即可打开数据文件夹。
关闭程序后直接替换 EXE 即可更新，已有数据会保留。每台电脑首次使用都需要在查询窗口登录。
原 Python 源码版的数据目录仍为项目中的 .python-data，两个版本分别保存数据。

操作提示
使用“系统鼠标”时，拖动会移动真实光标，请保持查询窗口在前台；按 Esc 或点击“暂停”可停止。
验证成功与激活信息以官网实际返回为准；需要人工验证时，完成后程序会继续查询。
“测试滑块”只尝试一次，不填写 SN、不提交设备查询。
重新尝试卡住的条目时，点击“重试当前 / 选中项”。

开源组件许可见随包的 licenses 目录。单文件 EXE 内也包含相同的许可文件。
